Singles Listing Upload

Use this page to test the new singles listing workflow without hopping through the repo manually. You can start from the manual intake template or from a collection-builder export, rebuild drafts from local card data, download the draft for spreadsheet review, then upload the reviewed draft back into the canonical file that the create script will consume.
1. Optional: upload a collection-builder CSV to auto-generate the singles intake file.
2. Or download the intake template and fill in the singles manually.
3. Upload the intake CSV to rebuild the enriched draft output from local data.
4. Download the draft CSV, mark rows as approved, then upload the reviewed draft back here.
