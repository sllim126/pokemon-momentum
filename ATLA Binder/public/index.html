ATLA Binder Layout Planner

Master-set planner for a pocket binder (6 x 6 by default; 4 x 4, 4 x 3 or 3 x 3 from the menu). Cards are grouped as side-by-side pairs with non-foil on the left and foil on the right, starting with TLA and then moving through TLE, promos, tokens, and inserts. Only officially confirmed printings and finishes reserve space. If a card image exists locally, the slot will show it. If not, the slot stays as a clean numbered placeholder.

Valuation

Live collection value uses Scryfall price fields for confirmed numbered TLA and TLE cards. Promo and insert categories remain unpriced unless we add a manual price map later.

This official-count version removes estimated promo and insert totals. It maps confirmed printings only, so some event or accessory items may be intentionally omitted until Wizards publishes exact unique counts.

How images work

Use one local image per card number. The planner reuses that same image for both non-foil and foil, then adds a small finish tag on top so the slots stay distinct. TLA and TLE can also fall back to the Scrydex image URLs automatically.

Collection tracking

Click any filled pocket to toggle whether you own that exact slot. Non-foil and foil are tracked separately when both actually exist, and your progress is saved in this browser.

Double-faced cards

The page uses the lower set number first, as requested. If you buy separate copies for each side, this layout still keeps the numbered slot order stable.

Compact sections

Sections that are entirely single-finish can be packed tightly with no blank partner pocket. Mixed sections still preserve left/right non-foil and foil pairing where that helps readability.

Missing scans

If an image file is not present yet, the slot falls back to a readable placeholder with the set number, finish, and section label so the binder map still works immediately.

Official-only counts

This planner intentionally omits categories where Wizards has not published an exact unique-card total, such as the full prerelease stamped pool and some token or art-card breakdowns.
