Store Tag Policy
================

Updated: August 8, 2026

Goal
----

Use Squarespace tags as a lightweight metadata layer that improves:

- store search
- internal maintenance
- quick filtering during cleanup and review

Tags should stay simpler and looser than categories.

Core rule
---------

Use categories for the main browse structure.

Use tags for:

- language
- special product traits
- selected set names
- temporary workflow markers when needed

Do not use tags as marketing copy, filler, or hype language.

Recommended tag groups
----------------------

1. Language tags

Use exactly one when applicable:

- `English`
- `Japanese`

2. Inventory-type tags

Use only when operationally helpful:

- `Singles`
- `Sealed`

Use these when they help separate workflows. `Singles` is especially useful
because singles and sealed often need different review and pricing passes.

3. Product-trait tags

Use when the product has a trait that matters for search, expectations, or
maintenance:

- `Pokemon Center`
- `Costco`
- `Random Design`
- `Poke Ball Tin`
- `Art Set`
- `Master Ball`
- `Promo`
- `Stamped`

Use these sparingly. A tag should communicate something a customer or operator
would actually want to filter by.

4. Set tags

Use set tags only for sets you actively expect to browse, search, or maintain.

Current priority set tags:

- `Perfect Order`
- `Chaos Rising`
- `Pitch Black`
- `Ascended Heroes`
- `Crown Zenith`
- `SV 151`
- `Black Bolt`
- `Surging Sparks`
- `Destined Rivals`

Set tags are useful even when some of those sets also exist as categories,
because tags still help with search and quick batch filtering.

5. Optional operator tags

Only use these if they solve a real internal problem:

- `Singles Intake`
- `Needs Review`
- `Image Pending`

These should not become permanent clutter. Use them as temporary workflow tags
and remove them once the batch is complete.

Tag rules
---------

1. Keep tags short.

Prefer:

- `Pokemon Center`
- `Random Design`
- `Art Set`

Avoid:

- `Streamer Friendly`
- `Collector`
- `Authentic`
- `Chase`

2. Prefer one canonical version of a label.

Good:

- `SV 151`
- `Poke Ball Tin`
- `Pokemon Center`

Avoid near-duplicates like:

- `Scarlet & Violet 151`
- `151`
- `Poke Ball`
- `Pokeball`
- `Mega Evolution`
- `Mega Evolutions`

3. Do not use tags for facts already handled by category or title.

Usually avoid tags like:

- `Booster Box`
- `Booster Bundle`
- `Booster Pack`
- `Elite`
- `Elite Trainer Box`

Those are better represented by categories and product titles.

4. Do not use tags as hype language.

Avoid:

- `Ripping`
- `Chase`
- `Collector`
- `Streamer Friendly`

Those may sound fun, but they do not age well as operational metadata.

5. Use tags for exceptions, not for every detail.

If something is unusual, like a random-design tin or Pokemon Center exclusive
product, tag it.

If something is normal and already obvious from category and title, skip the
extra tag.

Tags to phase out
-----------------

These are the kinds of tags to stop using going forward unless there is a very
specific reason:

- `Authentic`
- `Collector`
- `Chase`
- `Ripping`
- `Streamer Friendly`
- `Shrink`
- `Elite`
- `Booster Pack`
- `Booster Bundle`
- `Factory Sealed`
- `Japan Import`

Most of these either duplicate category information, repeat what the title
already says, or introduce vague wording that is hard to use consistently.

How to use this policy
----------------------

For new singles:

- use `English` or `Japanese`
- use `Singles`
- optionally add a set tag
- optionally add one special trait tag like `Master Ball`, `Stamped`, or
  `Promo`

For new sealed products:

- use `English` or `Japanese`
- optionally use `Sealed`
- optionally add a set tag
- add trait tags only when they matter, like `Pokemon Center`, `Costco`,
  `Random Design`, or `Poke Ball Tin`

For accessories or Printify-style products:

- keep them on a separate tagging scheme if they stay in the store
- do not force them into the sealed product tag system

Default examples
----------------

Good sealed examples:

- `English, Perfect Order`
- `English, Pokemon Center, Chaos Rising`
- `English, Poke Ball Tin, Random Design`
- `Japanese, Black Bolt`

Good singles examples:

- `English, Singles, Crown Zenith`
- `Japanese, Singles, Promo`
- `English, Singles, Master Ball`

Maintenance recommendation
--------------------------

During inventory cleanup, prefer:

- fewer tags
- more consistent tags
- tags that help with real filtering

That is better than having a large tag cloud full of one-off words that do not
support browsing or operations.
