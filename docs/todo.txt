Pokemon Momentum TODO
=====================

Last updated: 2026-11-11 (milestone: self-hosted; poke6s.com on our own server)

This is the single list of what to work on next. Whoever picks up the project (a person,
Claude, Codex or any other coding agent) should be able to start from this file without
the earlier conversations. `AGENTS.md` at the repository root says how to keep it current
and defines the "milestone" wrap-up routine. Completed items move to
`docs/todo_archive.txt`.

Status tags used below:

  [next]         pick these up first, top to bottom
  [in progress]  started; the note says where it stopped
  [waiting]      needs a decision or input from the owner before anyone starts
  [planned]      agreed, not started
  [parked]       on hold on purpose; do not start without asking the owner
  [idea]         not agreed yet; raise it with the owner before building
  [watching]     live; no work planned, but watch #bug-reports and fix what comes in

When you finish an item, move it to Recently Completed with the date and commit, then
archive older Recently Completed entries at the next milestone.
